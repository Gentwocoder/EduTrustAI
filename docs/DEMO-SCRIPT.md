# Three-minute hackathon demo

## 0:00–0:25 — Problem

Open the public site and explain that employers often wait days for manual academic verification while altered certificates can be difficult to detect.

## 0:25–1:10 — Issue

1. Open **Institution portal**.
2. Select **Issue credential**.
3. Point out the privacy panel: student details and the PDF stay off-chain.
4. Submit the sample credential and show the new registry entry.
5. Show the BOT Chain network, issuer wallet and hashes in the transaction panel.

## 1:10–1:45 — Verify

1. Return to the public verifier.
2. Verify `EDU-2026-00128`.
3. Show the verified institution, qualification and valid status.
4. Explain that no account is needed for public verification.

## 1:45–2:20 — Detect fraud

1. Select **Analyze altered sample**.
2. Show that AI detected a classification change from Second Class Upper to First Class.
3. Explain that the issued record remains independently checkable on BOT Chain.

## 2:20–2:45 — Revoke

1. Return to the institution portal.
2. Revoke a valid credential.
3. Explain that the historical record remains auditable while the public status changes.

## 2:45–3:00 — Close

Position EduTrust AI as a verification network that can plug into Lenage's existing School Management System and onboard real schools after the challenge.
